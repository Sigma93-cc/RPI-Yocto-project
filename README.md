# Проект сборки ОС SigmaStudio
* Основан на `Yocto-project`;
* Для сборки используется `kas`;
* Реализована поддержка дисплея `WaveShare`;
* Реализован сервис OTA-обновлений `SWUpdate`;
* Предустановлены пакеты `qt` и `boost`;
* Qt собран с поддержкой `linuxfb` и `evdev`;
* Добавлен `udev` для обнаружения дисплея `WaveShare`;
* Добавлен `psplash` с кастомным логотипом образа;
* Реализована схема A/B обновлений (`rootfs_a`, `rootfs_b`);
* Добавлены скрипты в UBoot с логикой монтирования активной `rootfs`;
* Добавлена версионированная сборка образа с привязкой к `git`;
* Добавлен `drop-in` к `80-ethernet.conf` с установкой статического IP для подключения к устройству.

## Поддерживаемые платы
* Raspberry Pi 3 Model B+.

## Требования
* Docker

## Процесс сборки
* Для запуска сборки используется скрипт `build.sh`;
* В процессе сборки настраивается Docker-контейнер на базе ОС `Ubuntu 22.04` с установкой зависимостей  для корректной работы `BitBake` и `kas`;
* Клонируются репозитории, прописанные в `kas_image.yml` для сборки образа.

## Артефакты сборки
 * каталог сборки: `build/tmp/deploy/images/${MACHINE}`;
 * образ `*.wic.bz2`;
 * SWUpdate-файл `*.swu` для OTA-обновления OC.

## Установка/обновление образа
* записать на SD-карту `*.wic.bz2` файл образа, если установка первичная. Для записи использовать  `bmaptool`;
* на порту 8080 настроен web-сервер SWUpdate для записи на устройство обновления с его автоматической установкой.
