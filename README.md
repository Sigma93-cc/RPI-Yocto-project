# Проект сборки ОС SigmaStudio, основанный на Yocto-project

## Поддерживаемые платы
Raspberry Pi 3 Model B+.

## Зависимости
Для сборки должен быть установлен Docker.

## Особенности
### Для запуска сборки используется скрипт `build.sh`;
* В процессе сборки настраивается Docker-контейнер на базе ОС `Ubuntu 22.04` с предустановленными зависимостями  для корректной работы BitBake и kas;
* Клонируются репозитории, прописанные в `kas_image.yml` для сборки образа;

## Артефакты сборки
 * образ, который хранится по пути `build/tmp/deploy/images/${MACHINE}/*.wic.bz2`;
 * SWUpdate-файл `build/tmp/deploy/images/${MACHINE}/*.swu` для OTA-обновления OC.

## Установка образа
* при первичной проливке образа необходимо записать на SD-карту *.wic.bz2 файл. Для проливки рекомендуется к использованию `bmaptool`.
* при последующих обновлениях на порту 8080 настроен web-сервер SWUpdate для проливки обновлений образа.
