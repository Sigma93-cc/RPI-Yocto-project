# Проект сборки ОС SigmaStudio, основанный на Yocto-project

## Поддерживаемые платы
Raspberry Pi 3 Model B+.

## Зависимости
Docker

## Процесс сборки
* Для запуска сборки используется скрипт `build.sh`;
* В процессе сборки настраивается Docker-контейнер на базе ОС `Ubuntu 22.04` с предустановленными зависимостями  для корректной работы `BitBake` и `kas`;
* Клонируются репозитории, прописанные в `kas_image.yml` для сборки образа;

## Артефакты сборки
 * каталог сборки: `build/tmp/deploy/images/${MACHINE}`;
 * образ *.wic.bz2`;
 * SWUpdate-файл `*.swu` для OTA-обновления OC.

## Установка образа
* при первичной установке образа необходимо записать на SD-карту *.wic.bz2 файл. Для записи рекомендуется к использованию `bmaptool`.
* при последующих обновлениях на порту 8080 настроен web-сервер SWUpdate для записи на устройство обновления и его последующей установки.
